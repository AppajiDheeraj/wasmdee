## Request

```
GET /runtime
```

No parameters required.

## Response Fields

### Engine

| Field | Description |
|---|---|
| `compiled_modules` | Currently warm compiled modules in memory |
| `compile_requests` | Total compilation attempts since startup |
| `compile_hits` | Requests served from warm pool (no recompile) |
| `evictions` | Modules evicted by scale-to-zero |
| `invocations` | Total function executions |
| `host_calls` | In-process function-to-function calls |
| `host_call_failures` | Failed host calls |

### Dispatcher

| Field | Description |
|---|---|
| `workers` | Currently active worker count |
| `min_workers` | Configured minimum |
| `max_workers` | Configured maximum |
| `accepted` | Total invocations admitted |
| `rejected` | Total invocations rejected (queue full) |
| `scale_ups` | Times new workers were spawned |
| `scale_downs` | Times idle workers retired |

### Function Stats (per function)

| Field | Description |
|---|---|
| `accepted` | Invocations admitted for this function |
| `rejected` | Invocations rejected for this function |
| `started` | Invocations that began execution |
| `completed` | Invocations that finished |
| `failed` | Invocations that errored or exited non-zero |
| `in_flight` | Currently executing |
| `ewma_latency_ms` | Rolling average latency |
| `ewma_arrival_rate` | Rolling average invocations/sec |
| `last_invoked_at` | Timestamp of last invocation |
| `last_error` | Most recent error (if any) |

### Preload

| Field | Description |
|---|---|
| `requested` | Functions that preload attempted |
| `compiled` | Successfully preloaded |
| `failed` | Array of `{name, err}` for failures |

## Example

```bash
curl http://127.0.0.1:8080/runtime | jq .
```
