## Overview

When you run `wasmdee serve`, an HTTP gateway exposes endpoints for function invocation and runtime observability. The gateway uses the same Wazero engine and bounded dispatcher as CLI invocations.

## Base URL

```
http://127.0.0.1:8080
```

Configurable with `--addr`.

## Endpoints

| Method | Path | Description |
|---|---|---|
| `POST` | `/invoke/{name}` | Invoke a deployed function |
| `GET` | `/functions` | List all deployed functions |
| `GET` | `/runtime` | Full runtime telemetry |
| `GET` | `/healthz` | Health check |

## Common Response Format

All endpoints return JSON with `Content-Type: application/json`.

### Error Response

```json
{
  "error": "function not found: unknown-func"
}
```

## HTTP Status Codes

| Code | Meaning |
|---|---|
| `200` | Success |
| `400` | Bad request (missing function name, invalid body) |
| `404` | Function not found in registry |
| `429` | Too many requests (dispatcher queue full) |
| `502` | Function exited with non-zero code |
| `503` | Service unavailable (dispatcher closed) |
| `500` | Internal server error |

## Request Limits

- Maximum request body: **8 MB**
- Read header timeout: **5 seconds**
- Invocation timeout: configurable via `--invoke-timeout` (default 10s)
