## Install wasmdee

<CodeGroup>
```bash Go Install
go install github.com/dheeraj/wasmdee/cmd/wasmdee@latest
```

```bash Build from Source
git clone https://github.com/dheeraj/wasmdee.git
cd wasmdee
make build
# binary is at ./bin/wasmdee
```
</CodeGroup>

---

## Write a function

wasmdee runs WASI command modules. Your function reads input from **stdin** and writes output to **stdout**. Any language that compiles to `.wasm` with WASI support works.

<CodeGroup>
```go Go (TinyGo)
package main

import (
    "fmt"
    "io"
    "os"
)

func main() {
    input, _ := io.ReadAll(os.Stdin)
    fmt.Printf("Hello from wasmdee! You said: %s", input)
}
```

```rust Rust
use std::io::{self, Read};

fn main() {
    let mut input = String::new();
    io::stdin().read_to_string(&mut input).unwrap();
    println!("Hello from wasmdee! You said: {}", input);
}
```
</CodeGroup>

Compile to Wasm:

<CodeGroup>
```bash TinyGo
tinygo build -o hello.wasm -target wasi .
```

```bash Rust
cargo build --target wasm32-wasi --release
cp target/wasm32-wasi/release/hello.wasm .
```
</CodeGroup>

---

## Deploy

```bash
wasmdee deploy hello.wasm --name hello
```

This validates the `.wasm` module, stores it in a content-addressed local module store, and registers it in the function registry.

---

## Invoke from CLI

```bash
wasmdee invoke hello --data '{"name":"world"}'
```

Pass arguments with `--arg`:

```bash
wasmdee invoke hello --arg one --arg two
```

---

## Start the HTTP gateway

```bash
wasmdee serve
```

The gateway starts at `http://127.0.0.1:8080` with:
- Preloaded compiled modules
- Autoscaling workers
- Bounded dispatch queue

---

## Invoke over HTTP

```bash
curl -X POST http://127.0.0.1:8080/invoke/hello \
  -d '{"name": "world"}'
```

Response:

```json
{
  "name": "hello",
  "stdout": "Hello from wasmdee! You said: {\"name\":\"world\"}",
  "stderr": "",
  "exit_code": 0,
  "latency_ms": 0.42
}
```
