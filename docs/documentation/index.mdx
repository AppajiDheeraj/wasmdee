## What is wasmdee?

wasmdee is a Wasm-native serverless function platform. Deploy a `.wasm` file, get an HTTP trigger, and run it through a shared in-process WebAssembly runtime instead of spinning up a container per function.

Built on ideas from [Faasm](https://github.com/faasm/faasm), [Catalyzer](https://www.usenix.org/conference/atc20/presentation/du), [Nightcore](https://www.usenix.org/conference/asplos21/presentation/jia), and [Cloudflare Workers](https://workers.cloudflare.com/). The project investigates how a shared Wasm runtime changes the startup, isolation, and resource trade-offs of container-based FaaS.

## Why wasmdee?

| Traditional FaaS | wasmdee |
|---|---|
| Container image per function | Content-addressed `.wasm` module |
| Process or container per replica | Shared Wazero runtime per node |
| Repeated startup work | Compiled-module reuse and file-backed cache |
| Replica scale-to-zero | Idle compiled-module eviction and rehydration |
| Network path between functions | Experimental in-process host-call ABI |
