## What is wasmdee?

wasmdee is a Wasm-native serverless function platform. Deploy a `.wasm` file, get an HTTP trigger, and run it through a shared in-process WebAssembly runtime instead of spinning up a container per function.

Built on ideas from [Faasm](https://github.com/faasm/faasm), [Catalyzer](https://www.usenix.org/conference/atc20/presentation/du), [Nightcore](https://www.usenix.org/conference/asplos21/presentation/jia), and [Cloudflare Workers](https://workers.cloudflare.com/) — designed to beat the cold-start and resource overhead of container-based FaaS platforms like OpenFaaS and AWS Lambda.

## Why wasmdee?

| Traditional FaaS | wasmdee |
|---|---|
| Container image per function | Single `.wasm` binary |
| Docker/Kubernetes scheduling | In-process Wasm isolation |
| 100ms+ cold starts | Sub-millisecond warm, under 10ms rehydrate |
| GB-scale memory per function | KB-scale Wasm linear memory |
| Network proxy between functions | Direct in-process host calls |
