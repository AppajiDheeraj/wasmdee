# wasmdee diagrams

Editable diagram assets for architecture documentation and presentations.

## Files

- `wasmdee_arrow_architecture.svg` - Arrow-style technical architecture board.
- `wasmdee_deep_architecture.svg` - dense engineering architecture board with control plane, hot path, benchmark, telemetry, and future runtime boundary.
- `wasmdee_event_trace.excalidraw` - Interview-ready Excalidraw map covering interfaces, deployment and routing, bounded dispatch, Wazero warm state, fresh WASI execution, pooled handler execution, scale-to-zero, telemetry, and multi-node evolution.
- `prompts.md` - Reusable prompts for generating more diagrams in the same style.

The SVG is plain text and can be edited directly in Figma, Illustrator, Inkscape,
or a code editor. The Excalidraw file can be opened at
https://excalidraw.com by using **Open** and selecting the `.excalidraw` file.
